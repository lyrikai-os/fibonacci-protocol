# Lyrikai: Fibonacci Protocol for UI/UX Design Agents: agent pack

*Lyrikai: Fibonacci Protocol for UI/UX Design Agents · version 1.0.0-rc.1 · MIT License · [www.lyrikai.com](https://www.lyrikai.com)*

The agent pack makes a design agent follow the Fibonacci Protocol when asked. Every file here is generated by `tools/build-pack/build-pack.mjs` from the specification, so it cannot drift from it. Licensed under the MIT License; see [www.lyrikai.com](https://www.lyrikai.com).

## What is in the pack

| File | For |
|---|---|
| `skills/lyrikai-fibonacci/` (in the repository root) | Any tool that reads Agent Skills (a folder with `SKILL.md`): Claude Code, Codex, Cursor. The one switch: `/lyrikai-fibonacci on`. |
| `AGENTS.md` | Tools that read `AGENTS.md`: Codex, Cursor and others. |
| `cursor/fibonacci-protocol.mdc` | A Cursor project rule (not always on). |
| `FP-AGENT.md` | The whole protocol for an agent in one file. Works in any LLM tool: attach or paste it. |

Activation, in any tool: type `/lyrikai-fibonacci on` or say "use Fibonacci design principles". Turn it off with `/lyrikai-fibonacci off`. Without the skill, ask the agent to read `FP-AGENT.md` and follow it.

## Install, by tool

Folder paths below come from each tool's own documentation, read on the build date of this pack (November 2026). Tools change; if a path no longer works, follow the linked page.

### Claude Code (skill)

Copy the folder `skills/lyrikai-fibonacci/` to:

- `~/.claude/skills/lyrikai-fibonacci/` for all your projects, or
- `.claude/skills/lyrikai-fibonacci/` inside a repository, to share it with the team.

Source: https://code.claude.com/docs/en/skills ("Personal skills" and "Project skills"). Then type `/lyrikai-fibonacci on`. Keep the `reference/` folder beside `SKILL.md`: the skill reads it.

### Codex (skill and AGENTS.md)

- Skill: copy `skills/lyrikai-fibonacci/` to `.agents/skills/lyrikai-fibonacci/` in the repository (Codex also reads `.agents/skills` in parent folders up to the repository root), or to `~/.agents/skills/lyrikai-fibonacci/` for all projects. Invoke with `$lyrikai-fibonacci` or from `/skills`; it may also be selected from its description. Source: https://developers.openai.com/codex/skills (redirects to https://learn.chatgpt.com/docs/build-skills).
- AGENTS.md: place `AGENTS.md` at the repository root, or in a subfolder for that part of the tree (files closer to the working directory take precedence). For all projects use `AGENTS.md` in the Codex home folder, `~/.codex/` by default. Source: https://developers.openai.com/codex/guides/agents-md (redirects to https://learn.chatgpt.com/docs/agent-configuration/agents-md). If you already have an `AGENTS.md`, append this one rather than replacing yours. Keep `FP-AGENT.md` in the same folder, because `AGENTS.md` links to it.

### Cursor (rule, skill, AGENTS.md)

- Rule: copy `cursor/fibonacci-protocol.mdc` to `.cursor/rules/fibonacci-protocol.mdc` in the project. Project rules live in `.cursor/rules` and use the `.mdc` extension with `description`, `globs` and `alwaysApply` frontmatter. This rule is `alwaysApply: false`, so it is used when the description or the files match, or when you mention it by name. Source: https://cursor.com/docs/context/rules. Also copy `FP-AGENT.md` into the project (for example `docs/FP-AGENT.md`) so the rule can point to it.
- Skill: Cursor supports Agent Skills. Copy `skills/lyrikai-fibonacci/` to `.cursor/skills/` or `.agents/skills/` in the project, or to `~/.cursor/skills/` or `~/.agents/skills/` for all projects. Cursor also loads the Claude and Codex skill folders (`.claude/skills/`, `.codex/skills/`). Source: https://cursor.com/docs/context/skills.
- AGENTS.md: Cursor reads `AGENTS.md` from the project root and subfolders. Source: https://cursor.com/docs/context/rules.

### Any other tool

Use `FP-AGENT.md`: give it to the agent as context (a rules file, a system prompt, an attachment). If the tool reads `AGENTS.md`, use that file. If it reads Agent Skills, copy the skill folder to the folder the tool documents.

## Check your install

Ask the agent: `/lyrikai-fibonacci explain FP-SPACE-01`. It should print the rule's text, level, status, test and evidence. Then `/lyrikai-fibonacci on`; the reply should end with the About line:

Lyrikai: Fibonacci Protocol for UI/UX Design Agents · spec 1.0.0-rc.1 · MIT License · https://www.lyrikai.com

## Rebuild

`node tools/build-pack/build-pack.mjs` regenerates every file. `node tools/build-pack/build-pack.mjs --check` exits 1 if a committed file is out of date.
